# Rešitve maturitetne pole iz matematike 
Ta repozitorij vsebuje **rešene naloge 1. pole osnovne ravni spomladanskega roka 2023** iz mature iz matematike. Ustvarjene so bile v okviru predmeta Programska oprema pri pouku, kjer je bil cilj je omogočiti jasne in razumljive rešitve. Rešitve so bile spisane na roko, zato se lahko pojavi kakšna vsebinska napaka. Sicer pa so bile preverjene z uradnimi rešitvami in se z njimi skladajo.

Skratka, tukaj si lahko ogledaš [1. polo spomladanskega roka 2023](https://www.ric.si/mma/M231-401-1-1.pdf/20231009130318/?m=1696849398), tukaj pa so [moje rešitve](https://meglicka.github.io/Matura-pomlad-2023-OR-pola-1/). Srečno pri učenju!
